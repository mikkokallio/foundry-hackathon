# Glossary (synthetic)

| Term | Meaning |
|---|---|
| Installed base | All machines delivered to customers that the organization services |
| Work order | A unit of service work assigned to a technician |
| Asset health score | 0–100 score per asset produced by the predictive maintenance models (DP-001) |
| iPaaS | The Integration Platform (SYS-010) used for system-to-system integrations |
| Data product | A curated, owned dataset with a documented contract (`DP-NNN`) |
| Proposal | A submitted new or updated document waiting for review in the shared docs store |
| Librarian | The architecture role that reviews and publishes proposals |
